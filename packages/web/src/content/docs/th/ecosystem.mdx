ชุดโครงการชุมชนที่สร้างขึ้นบน FrenixCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ FrenixCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-frenixcode](https://github.com/awesome-frenixcode/awesome-frenixcode) และ [frenixcode.cafe](https://frenixcode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
