A collection of community projects built on FrenixCode.

:::note
Want to add your FrenixCode related project to this list? Submit a PR.
:::

You can also check out [awesome-frenixcode](https://github.com/awesome-frenixcode/awesome-frenixcode) and [frenixcode.cafe](https://frenixcode.cafe), a community that aggregates the ecosystem and community.
