Eine Sammlung von Community-Projekten, die auf FrenixCode basieren.

:::note
Möchten Sie Ihr FrenixCode-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-frenixcode](https://github.com/awesome-frenixcode/awesome-frenixcode) und [frenixcode.cafe](https://frenixcode.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
