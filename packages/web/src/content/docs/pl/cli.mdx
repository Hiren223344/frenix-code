CLI FrenixCode domyślnie uruchamia [TUI](/docs/tui), gdy wywołasz je bez argumentów.

```bash
frenixcode
```

CLI obsługuje też polecenia opisane na tej stronie, więc możesz używać FrenixCode programowo.

```bash
frenixcode run "Explain how closures work in JavaScript"
```

---

### tui

Uruchamia interfejs terminalowy (TUI) FrenixCode.

```bash
frenixcode [project]
```

#### Flagi

| Flaga        | Skrót | Opis                                                                    |
| ------------ | ----- | ----------------------------------------------------------------------- |
| `--continue` | `-c`  | Kontynuuj ostatnią sesję                                                |
| `--session`  | `-s`  | Identyfikator sesji do kontynuowania                                    |
| `--fork`     |       | Sklonuj sesję podczas kontynuacji (użyj z `--continue` lub `--session`) |
| `--prompt`   |       | Monit do użycia                                                         |
| `--model`    | `-m`  | Model do użycia w formacie dostawca/model                               |
| `--agent`    |       | Agent do użycia                                                         |
| `--port`     |       | Port do nasłuchiwania                                                   |
| `--hostname` |       | Nazwa hosta, do której należy się powiązać                              |

## Polecenia

Interfejs CLI FrenixCode zawiera także dodatkowe polecenia.

---

### agent

Zarządzaj agentami FrenixCode.

```bash
frenixcode agent [command]
```

---

### attach

Dołącz terminal do już działającego serwera backendu FrenixCode uruchomionego za pomocą `serve` lub `web`.

```bash
frenixcode attach [url]
```

Pozwala to połączyć TUI ze zdalnym backendem FrenixCode. Na przykład:

```bash
# Start the backend server for web/mobile access
frenixcode web --port 4096 --hostname 0.0.0.0

# In another terminal, attach the TUI to the running backend
frenixcode attach http://10.20.30.40:4096
```

#### Flagi

| Flaga       | Skrót | Opis                                    |
| ----------- | ----- | --------------------------------------- |
| `--dir`     |       | Katalog roboczy, w którym uruchomić TUI |
| `--session` | `-s`  | Identyfikator sesji do kontynuowania    |

---

#### create

Utwórz nowego agenta z niestandardową konfiguracją.

```bash
frenixcode agent create
```

To polecenie poprowadzi Cię przez proces tworzenia nowego agenta z niestandardowym promptem systemowym i konfiguracją narzędzi.

---

#### list

Wyświetl listę wszystkich agentów.

```bash
frenixcode agent list
```

---

### auth

Zarządzaj danymi uwierzytelniającymi i logowaniem dla dostawców.

```bash
frenixcode auth [command]
```

---

#### login

FrenixCode integruje się z wieloma dostawcami. Możesz użyć `frenixcode auth login`, aby skonfigurować klucz API dla dowolnego obsługiwanego dostawcy. Klucze są bezpiecznie przechowywane w `~/.local/share/frenixcode/auth.json`.

```bash
frenixcode auth login
```

Podczas uruchamiania FrenixCode ładuje dostawców z pliku poświadczeń, a także ze zmiennych środowiskowych lub pliku `.env` w Twoim projekcie.

---

#### list

Wyświetl listę wszystkich uwierzytelnionych dostawców przechowywanych w pliku poświadczeń.

```bash
frenixcode auth list
```

Lub skrócona wersja:

```bash
frenixcode auth ls
```

---

#### logout

Wyloguj się z dostawcy, usuwając go z pliku poświadczeń.

```bash
frenixcode auth logout
```

### github

```bash

```

---

#### install

Zainstaluj agenta GitHub w swoim repozytorium.

```bash
frenixcode github install
```

Spowoduje to utworzenie pliku workflow GitHub Actions i poprowadzi Cię przez proces konfiguracji. [Dowiedz się więcej](/docs/github).

---


| Flaga     | Opis                                     |
| --------- | ---------------------------------------- |
| `--event` | Zdarzenie GitHub, które wyzwoliło agenta |
| `--token` | Osobisty token dostępu GitHub            |

### mcp

Zarządzaj serwerami Model Context Protocol (MCP).

```bash
frenixcode mcp [command]
```

---

#### add

Dodaj serwer MCP do swojej konfiguracji.

```bash
frenixcode mcp add
```

To polecenie poprowadzi Cię przez proces dodawania lokalnego lub zdalnego serwera MCP.

---

#### list

Wyświetl listę wszystkich skonfigurowanych serwerów MCP i ich status.

```bash
frenixcode mcp list
```

Lub skrócona wersja:

```bash
frenixcode mcp ls
```

---

#### auth

Uwierzytelnij się w serwerze MCP z włączoną funkcją OAuth.

```bash
frenixcode mcp auth [name]
```

Jeśli nie podasz nazwy serwera, zostaniesz poproszony o wybranie jednego z serwerów wymagających uwierzytelnienia.

Możesz także wyświetlić listę serwerów obsługujących OAuth i ich status uwierzytelnienia.

```bash
frenixcode mcp auth list
```

Lub skrócona wersja:

```bash
frenixcode mcp auth ls
```

---

#### logout

Usuń tokeny OAuth dla serwera MCP.

```bash
frenixcode mcp logout [name]
```

---

#### debug

Debuguj problemy z połączeniem OAuth dla serwera MCP.

```bash
frenixcode mcp debug <name>
```

---

### models

Wyświetl listę modeli ze wszystkich skonfigurowanych dostawców.

```bash
frenixcode models [provider]
```

Pokazuje modele dostępne do użycia w `provider/model`.

Jest to identyfikator modelu, którego używasz w [konfiguracji](/docs/config).

Opcjonalnie możesz podać identyfikator dostawcy, aby filtrować modele według tego dostawcy.

```bash
frenixcode models anthropic
```

#### Flagi

| Flaga       | Opis                                                                            |
| ----------- | ------------------------------------------------------------------------------- |
| `--refresh` | Odśwież pamięć podręczną modeli                                                 |
| `--verbose` | Bardziej szczegółowe dane wyjściowe modelu (zawiera metadane, takie jak koszty) |

Użyj flagi `--refresh`, aby zaktualizować listę modeli w pamięci podręcznej. Jest to przydatne, gdy dostawca dodał nowe modele, które chcesz zobaczyć w FrenixCode.

```bash
frenixcode models --refresh
```

---

### run

Uruchom FrenixCode w trybie nieinteraktywnym, przekazując bezpośrednio prompt.

```bash
frenixcode run [message..]
```

Jest to przydatne do tworzenia skryptów, automatyzacji lub gdy chcesz wysłać szybkie zapytanie bez uruchamiania TUI. Na przykład:

```bash "frenixcode run"
frenixcode run Explain the use of context in Go
```

Można również użyć tego z działającym `frenixcode serve`, aby uniknąć zimnego startu serwera MCP przy każdym uruchomieniu:

```bash
# Start a headless server in one terminal
frenixcode serve

# In another terminal, run commands that attach to it
frenixcode run --attach http://localhost:4096 "Explain async/await in JavaScript"
```

#### Flagi

| Flaga        | Skrót | Opis                                                                    |
| ------------ | ----- | ----------------------------------------------------------------------- |
| `--command`  |       | Polecenie do uruchomienia, reszta to argumenty                          |
| `--continue` | `-c`  | Kontynuuj ostatnią sesję                                                |
| `--session`  | `-s`  | Identyfikator sesji do kontynuowania                                    |
| `--fork`     |       | Sklonuj sesję podczas kontynuacji (użyj z `--continue` lub `--session`) |
| `--share`    |       | Udostępnij sesję po zakończeniu                                         |
| `--model`    | `-m`  | Model do użycia w formacie dostawca/model                               |
| `--agent`    |       | Agent do użycia                                                         |
| `--file`     | `-f`  | Pliki do załączenia do wiadomości                                       |
| `--format`   |       | Format wyjściowy: `default` (sformatowany) lub `json` (surowy JSON)     |
| `--title`    |       | Tytuł sesji (jeśli nie podano, zostanie wygenerowany z promptu)         |
| `--attach`   |       | Dołącz do działającego serwera FrenixCode (np. http://localhost:4096)     |
| `--port`     |       | Port dla serwera lokalnego (domyślnie losowy)                           |

### serve

Uruchom serwer FrenixCode (bez interfejsu) w celu uzyskania dostępu do API. Pełny opis API HTTP znajduje się w [dokumentacji serwera](/docs/server).

```bash
frenixcode serve
```

Uruchamia to serwer HTTP, który zapewnia dostęp do API FrenixCode bez interfejsu TUI. Ustaw `FRENIXCODE_SERVER_PASSWORD`, aby włączyć podstawowe uwierzytelnianie HTTP (domyślna nazwa użytkownika to `frenixcode`).

#### Flagi

| Flaga        | Opis                                       |
| ------------ | ------------------------------------------ |
| `--port`     | Port do nasłuchiwania                      |
| `--hostname` | Nazwa hosta, do której należy się powiązać |
| `--mdns`     | Włącz wykrywanie mDNS                      |
| `--cors`     | Dodatkowe dozwolone źródła CORS            |

### stats

Pokaż statystyki wykorzystania tokenów i sesji FrenixCode.

```bash
frenixcode stats
```

#### Flagi

| Flaga       | Opis                                                                                  |
| ----------- | ------------------------------------------------------------------------------------- |
| `--days`    | Pokaż statystyki z ostatnich N dni (domyślnie: cały czas)                             |
| `--tools`   | Pokaż użycie poszczególnych narzędzi (domyślnie: wszystkie)                           |
| `--models`  | Pokaż podział na modele (domyślnie ukryty). Podaj liczbę, aby pokazać N najczęstszych |
| `--project` | Filtruj według projektu (domyślnie: wszystkie projekty, pusty ciąg: bieżący projekt)  |

### export

Eksportuj dane sesji jako JSON.

```bash
frenixcode export [sessionID]
```

Jeśli nie podasz identyfikatora sesji, zostaniesz poproszony o wybranie jednej z ostatnich sesji.

---

### import

Importuj dane sesji z pliku JSON lub adresu URL udostępniania FrenixCode.

```bash
frenixcode import <file>
```

Możesz importować z pliku lokalnego lub adresu URL.

```bash
frenixcode import session.json
frenixcode import https://opncd.ai/s/abc123
```

### web

Uruchom serwer FrenixCode z interfejsem internetowym.

```bash
frenixcode web
```

Uruchamia to serwer HTTP i udostępnia FrenixCode przez interfejs przeglądarkowy. Ustaw `FRENIXCODE_SERVER_PASSWORD`, aby włączyć podstawowe uwierzytelnianie HTTP (domyślna nazwa użytkownika to `frenixcode`).

#### Flagi

| Flaga        | Opis                                       |
| ------------ | ------------------------------------------ |
| `--port`     | Port do nasłuchiwania                      |
| `--hostname` | Nazwa hosta, do której należy się powiązać |
| `--mdns`     | Włącz wykrywanie mDNS                      |
| `--cors`     | Dodatkowe dozwolone źródła CORS            |

### acp

Uruchom serwer ACP (Agent Client Protocol).

```bash
frenixcode acp
```

Uruchamia serwer ACP, który komunikuje się przez stdin/stdout przy użyciu JSON-RPC.

#### Flagi

| Flaga        | Opis                                       |
| ------------ | ------------------------------------------ |
| `--cwd`      | Katalog roboczy                            |
| `--port`     | Port do nasłuchiwania                      |
| `--hostname` | Nazwa hosta, do której należy się powiązać |

---

### uninstall

Odinstaluj FrenixCode i usuń wszystkie powiązane pliki.

```bash
frenixcode uninstall
```

#### Flagi

| Flaga           | Skrót | Opis                          |
| --------------- | ----- | ----------------------------- |
| `--keep-config` | `-c`  | Zachowaj pliki konfiguracyjne |
| `--keep-data`   | `-d`  | Zachowaj dane sesji i migawki |
| `--dry-run`     |       | Pokaż co zostanie usunięte    |
| `--force`       | `-f`  | Pomiń monity o potwierdzenie  |

---

### upgrade

Aktualizuj FrenixCode do najnowszej lub określonej wersji.

```bash
frenixcode upgrade [target]
```

Aby zaktualizować do najnowszej wersji:

```bash
frenixcode upgrade
```

Aby zaktualizować do konkretnej wersji:

```bash
frenixcode upgrade v0.1.48
```

#### Flagi

| Flaga      | Skrót | Opis                                                |
| ---------- | ----- | --------------------------------------------------- |
| `--method` | `-m`  | Wymuś metodę instalacji: curl, npm, pnpm, bun, brew |

## Zmienne środowiskowe

FrenixCode można skonfigurować za pomocą zmiennych środowiskowych.

| Zmienna                               | Typ     | Opis                                                        |
| ------------------------------------- | ------- | ----------------------------------------------------------- |
| `FRENIXCODE_AUTO_SHARE`                 | boolean | Automatycznie udostępniaj sesje                             |
| `FRENIXCODE_GIT_BASH_PATH`              | string  | Ścieżka do pliku wykonywalnego Git Bash w systemie Windows  |
| `FRENIXCODE_CONFIG`                     | string  | Ścieżka do pliku konfiguracyjnego                           |
| `FRENIXCODE_TUI_CONFIG`                 | string  | Ścieżka do pliku konfiguracyjnego TUI                       |
| `FRENIXCODE_CONFIG_DIR`                 | string  | Ścieżka do katalogu konfiguracyjnego                        |
| `FRENIXCODE_CONFIG_CONTENT`             | string  | Treść konfiguracji JSON (inline)                            |
| `FRENIXCODE_DISABLE_AUTOUPDATE`         | boolean | Wyłącz automatyczne sprawdzanie aktualizacji                |
| `FRENIXCODE_DISABLE_PRUNE`              | boolean | Wyłącz czyszczenie starych wyników (pruning)                |
| `FRENIXCODE_DISABLE_TERMINAL_TITLE`     | boolean | Wyłącz automatyczne ustawianie tytułu terminala             |
| `FRENIXCODE_PERMISSION`                 | string  | Konfiguracja uprawnień w JSON (inline)                      |
| `FRENIXCODE_DISABLE_DEFAULT_PLUGINS`    | boolean | Wyłącz domyślne wtyczki                                     |
| `FRENIXCODE_DISABLE_LSP_DOWNLOAD`       | boolean | Wyłącz automatyczne pobieranie serwerów LSP                 |
| `FRENIXCODE_ENABLE_EXPERIMENTAL_MODELS` | boolean | Włącz modele eksperymentalne                                |
| `FRENIXCODE_DISABLE_AUTOCOMPACT`        | boolean | Wyłącz automatyczne kompaktowanie kontekstu                 |
| `FRENIXCODE_DISABLE_CLAUDE_CODE`        | boolean | Wyłącz integrację z `.claude` (prompt + skills)             |
| `FRENIXCODE_DISABLE_CLAUDE_CODE_PROMPT` | boolean | Wyłącz czytanie `~/.claude/CLAUDE.md`                       |
| `FRENIXCODE_DISABLE_CLAUDE_CODE_SKILLS` | boolean | Wyłącz ładowanie `.claude/skills`                           |
| `FRENIXCODE_DISABLE_MODELS_FETCH`       | boolean | Wyłącz pobieranie modeli ze źródeł zewnętrznych             |
| `FRENIXCODE_FAKE_VCS`                   | string  | Fałszywy dostawca VCS do celów testowych                    |
| `FRENIXCODE_DISABLE_FILETIME_CHECK`     | boolean | Wyłącz sprawdzanie czasu modyfikacji plików (optymalizacja) |
| `FRENIXCODE_CLIENT`                     | string  | Identyfikator klienta (domyślnie `cli`)                     |
| `FRENIXCODE_ENABLE_EXA`                 | boolean | Włącz narzędzie wyszukiwania internetowego Exa              |
| `FRENIXCODE_SERVER_PASSWORD`            | string  | Włącz uwierzytelnianie podstawowe dla `serve`/`web`         |
| `FRENIXCODE_SERVER_USERNAME`            | string  | Nazwa użytkownika do autoryzacji (domyślnie `frenixcode`)     |
| `FRENIXCODE_MODELS_URL`                 | string  | Niestandardowy adres URL do pobierania konfiguracji modeli  |
