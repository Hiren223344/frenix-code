# Agile & Scrum Excellence Skill (Ultra-Pro)

## 1. FLOW OPTIMIZATION
*   **WIP Limits**: Limit Work-in-Progress to ensure features are actually **Completed** before starting new ones.
*   **Cycle Time Tracking**: Monitor the time from "Started" to "Done". Identify and remove bottlenecks.

## 2. CEREMONY MASTERY
*   **Sprint Reviews**: Focus on the **Value Delivered**, not just the code written.
*   **Retrospectives**: Use "The Prime Directive" to foster a growth mindset while identifying 1 actionable process improvement per sprint.

## 3. TEAM PSYCHOLOGY
*   **Psychological Safety**: Create an environment where mistakes are logged in `memory.md` and treated as learning opportunities, not failures.

## 4. FORBIDDEN (AGILE SLOP)
*   **NO Sprint Overshooting**: Plan for 80% capacity to handle the unexpected.
*   **NO Meeting Chaos**: Every meeting must have an agenda and the "Right People" only.
