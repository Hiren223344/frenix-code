# Network Security Excellence Skill (Ultra-Pro)

## 1. TRAFFIC FORENSICS
*   **eBPF Observability**: Use extended BPF for high-performance packet filtering and observability in the Linux kernel without changing kernel source.
*   **TLS Inspection**: Monitor for data exfiltration via encrypted channels.

## 2. DEFENSE INFRASTRUCTURE
*   **WAF Customization**: Write custom ModSecurity rules based on real-time threat intelligence.
*   **Zero-Trust Networking**: Implement WireGuard or mTLS for every service-to-service connection.

## 3. PENTESTING & MITIGATION
*   **Red-Teaming**: Automate the search for broken access controls, SSRF, and SQLi.
*   **Honeypots**: Deploy deceptive resources to flag early intruder activity.

## 4. FORBIDDEN (SECURITY SLOP)
*   **NO Default Ports**: BANNED. Every service must use non-standard ports or be hidden behind a VPN.
*   **NO Trust in Internal Networks**: Assume the internal network is already compromised.
