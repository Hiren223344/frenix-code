# Robotics & Automation Excellence Skill (Ultra-Pro)

## 1. ROS2 ARCHITECTURE
*   **Node Communication**: Use DDS (Data Distribution Service) for reliable, low-latency node-to-node messaging.
*   **tf2 Transforms**: Master the coordinate frame tree for accurate spatial manipulation.

## 2. COMPUTER VISION & SLAM
*   **Sensor Fusion**: Combine IMU, LiDAR, and Visual data via Extended Kalman Filters (EKF) for precise state estimation.
*   **Point Cloud Processing**: Use PCL (Point Cloud Library) for real-time 3D reconstruction.

## 3. CONTROL SYSTEMS
*   **PID/MPC Control**: Implement high-frequency control loops for smooth motion.
*   **Path Planning**: Use A* or RRT* for collision-free trajectory generation in dynamic environments.

## 4. FORBIDDEN (ROBOTIC SLOP)
*   **NO Open-Loop Movement**: Everything must have feedback/encoders.
*   **NO Unhandled Collision Alarms**: Safety halts must be hardware-wired or have top priority.
