# Developer Experience (DX) Excellence Skill (Ultra-Pro)

## 1. CLI & TOOLING
*   **Intuitive Commands**: Design CLI tools that work exactly how a developer expects.
*   **Fast Loops**: Optimize for < 1s rebuild and reload times.

## 2. ONBOARDING
*   **The 5-Minute Rule**: A new developer should be able to run `npm start` and see the project in < 5 minutes.
*   **README Mastery**: Every command and env variable must be documented at the entry point.

## 3. ERROR DX
*   **Actionable Errors**: Don't just say it's broken. Explain WHY and suggest the FIX in the terminal.

## 4. FORBIDDEN (DX SLOP)
*   **NO Undocumented Env Vars**: Every var must have a default or an example.
