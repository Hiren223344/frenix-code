# Product Ownership Excellence Skill (Ultra-Pro)

## 1. STRATEGIC PRIORITIZATION
*   **RICE Scoring**: Rank every feature by Reach, Impact, Confidence, and Effort. Never build a "low-impact, high-effort" feature.
*   **The MVP Filter**: Strip features down to their "Job to be Done". Launch fast, learn faster.

## 2. USER-CENTRIC DESIGN
*   **User Personas**: Every feature must solve a pain point for a specific, documented persona.
*   **Feedback Loops**: Proactively integrate user interviews and data analytics into the product roadmap.

## 3. STAKEHOLDER ALIGNMENT
*   **Roadmap Communication**: Maintain a live, transparent roadmap that balances technical debt with feature development.

## 4. FORBIDDEN (PO SLOP)
*   **NO Features Without Metrics**: If we can't measure the success of a feature, we don't build it.
