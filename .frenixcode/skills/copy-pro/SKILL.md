# Copywriting Excellence Skill (Ultra-Pro)

## 1. CONVERSION COPY
*   **The Hook**: Write headlines that grab attention in < 3 seconds.
*   **Action-Oriented Buttons**: Use active, goal-focused language ("Scale now" instead of "Submit").

## 2. TECHNICAL STORYTELLING
*   **De-Complexification**: Simplify complex technical architectures into compelling human stories.
*   **The Bridge**: Connect the "Feature" to the "Benefit" in every sentence.

## 3. GLOBAL BRAND TONE
*   **Consistency**: Maintain one single voice across Docs, UI, and Marketing.
*   **Humor & Wit**: Use subtle humor to reduce user frustration during errors.

## 4. FORBIDDEN (COPY SLOP)
*   **NO Jargon Without Explanation**: Never assume the user knows the acronym.
