# Creative UX Excellence Skill (Ultra-Pro)

## 1. CANVAS & WEBGL
*   **Physics UI**: Implement spring-based interactions that feel organic, not linear.
*   **Custom Shaders**: Use fragment shaders to create unique backgrounds, distortions, and transitions (Section 11 of `taste-skill`).

## 2. SOUND DESIGN
*   **Micro-sounds**: Use subtle audio feedback for interactions to increase user immersion.
*   **Web Audio API**: Dynamically generate or modulate soundscapes based on user movement/scrolling.

## 3. EXPERIMENTAL LAYOUTS
*   **Non-Boring Grids**: Use skewed, floating, or perspective-shifted layouts to differentiate the brand experience.
*   **3D Elements**: Integrate Three.js/React Three Fiber for interactive 3D hero assets.

## 4. FORBIDDEN (CREATIVE SLOP)
*   **NO Laggy Animations**: Every creative element must be hardware-accelerated.
*   **NO Accessibility Sacrifice**: Creative elements must not block the core usability of the site.
