# Ethics & Safety Excellence Skill (Ultra-Pro)

## 1. JAILBREAK PREVENTION
*   **System Prompt Hardening**: Layered protection to prevent LLMs from leaking internal instructions.
*   **Input Sanitization**: Use high-fidelity safety models to scan user input before it hits the primary LLM.

## 2. BIAS & FAIRNESS
*   **Dataset Auditing**: Scan RAG sources for biased or harmful content. Ensure AI outputs representative and fair perspectives.
*   **Red-Teaming**: Actively attempt to provoke harmful AI outputs to build defense patterns (Section 5 of `debugging-pro`).

## 3. TRANSPARENCY
*   **AI Disclosures**: Clearly label AI-generated content. Provide "Why X was suggested" context when appropriate.
*   **Accountability**: Every AI action must be traceable to a specific prompt and context.

## 4. FORBIDDEN (SAFETY SLOP)
*   **NO Unbounded Agency**: AI must never have destructive file system access without manual oversight.
*   **NO Black-box Logic**: Strive for interpretable prompts and clear decision trees.
