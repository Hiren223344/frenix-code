# Growth & SEO Excellence Skill (Ultra-Pro)

## 1. TECHNICAL SEO (SEMANTIC MASTERY)
*   **Semantic HTML**: Use strictly appropriate tags (`<main>`, `<article>`, `<nav>`). One `<h1>` per page.
*   **Metadata Architecture**: Implement dynamic `JSON-LD` (Schema.org) for search engine rich snippets. Generate ultra-high quality OpenGraph images for every page.
*   **Sitemap & Indexing**: Automate `sitemap.xml` and `robots.txt` generation. Ensure fast indexing via Google Search Console API.

## 2. ACCESSIBILITY (A11Y) AS A GROWTH LEVER
*   **WCAG 2.1 Compliance**: Target Level AA as the minimum. Ensure perfect keyboard navigation and screen-reader support (`aria-labels`, `role` attributes).
*   **Contrast & Legibility**: Proactively fix color contrast issues. Use relative units (`rem`, `em`) for fluid typography that respects user system settings.

## 3. CORE WEB VITALS (VERCEL-SPEED)
*   **Performance Budgeting**: Mandate LCP (Largest Contentful Paint) < 1s and CLS (Cumulative Layout Shift) of 0.
*   **Resource Prioritization**: Use `next/font`, `next/image`, and `priority` flags for hero assets. Pre-connect to critical domains.

## 4. CONVERSION RATE OPTIMIZATION (CRO)
*   **A/B Infrastructure**: Design components to be easily toggled for experiments. Use Edge Middleware for zero-flicker URL redirection.
*   **Micro-Conversions**: Track and optimize for small interactions (scroll depth, video watch time) that lead to final conversions.

## 5. FORBIDDEN (GROWTH SLOP)
*   **NO Invisible Content**: Cloaking or hidden text is an SEO sin. If it's there for SEO, it must be there for the user.
*   **NO Broken Internal Links**: Scan for 404s in every deployment.
*   **NO Missing Alt Text**: An image without an `alt` tag is a failure of both SEO and Accessibility.
*   **NO Blocked Crawlers**: Ensure preview environments are `noindex`, but production is fully crawlable.
